# 営業ログ端末（SalesLogDevice）— アプリ概要

## これは何のアプリ？

**営業の現場活動を「ボタンひとつ」で記録し、日報作成までを自動化する Android アプリ。**

営業担当者がスマホ（Pixel 想定）を持ち歩き、訪問のたびに最小限の操作をするだけで、
位置情報・滞在時間・商談メモ（録音の文字起こし＋AI要約）が自動でたまり、
1日の終わりに**日報が自動生成**され、**Googleスプレッドシート／ドライブに集約**される。

狙いは2つ:
- **入力の手間をほぼゼロに**（報告書づくりの時間を営業活動に戻す）
- **AIを端末内（オンデバイス）で動かしてAPIコストを0円に**

---

## 1日の使い方（基本フロー）

```
[営業開始] ──→ [訪問チェックイン] ──→ (商談・録音) ──→ [チェックアウト] ──→ … 繰り返し … ──→ [営業終了]
   │                │                      │                   │                                    │
 GPS取得         会社名/担当を手入力      Recorderの文字起こしを       滞在時間を自動計算               日報を自動生成し
 営業中に          ＋GPS自動取得          共有→自動で要約＆訪問に紐付け                                  Sheets/Driveへ集約
```

1. **営業開始**：ウィジェット or アプリのボタン。GPSで開始位置を記録し「営業中」へ。
2. **訪問チェックイン**：訪問先に着いたら会社名・担当者名を入力（GPSは自動）。「訪問中」へ。
3. **商談メモ**：Pixel Recorder 等で録音→文字起こしした結果を**このアプリに共有**すると、
   自動で要約が付き、進行中の訪問に紐づく。
4. **チェックアウト**：訪問終了。滞在時間を自動計算。
5. **営業終了**：その日の**日報を自動生成**し、Driveに保存＆Sheetsに活動履歴を追記。

> 状態は「未開始 / 営業中 / 訪問中 / 営業終了済み」の4つで管理。
> 訪問中は「営業終了」できない等、矛盾しないようガードしている。

---

## 主な機能

- **ホーム画面ウィジェット**：アプリを開かず「営業開始／チェックアウト／営業終了」を操作
- **稼働セッション管理**：1日=1セッション。開始/終了時刻・位置を記録
- **訪問ログ**：訪問先ごとにチェックイン〜アウト、滞在時間、位置、メモを記録
- **位置情報の自動取得**：開始・チェックイン・チェックアウト時にGPSを自動取得
- **録音文字起こしの取り込み**：他アプリ（Pixel Recorder等）からの共有テキストを受信し、進行中の訪問へ自動紐付け
- **オンデバイスAI要約**：受け取った文字起こしを端末内で要約（要点・次アクションを抽出）
- **日報の自動生成**：稼働・訪問・商談メモ・次アクションをMarkdownの日報に整形
- **日報プレビュー**：生成された日報を画面で確認
- **Googleスプレッドシート連携**：活動履歴を1行=1訪問で追記
- **Googleドライブ連携**：日報ファイルを保存しURLを記録
- **同期ログ**：Sheets/Driveへの送信成否を記録し、失敗時は再送できる土台
- **設定**：担当者名・チーム名・スプレッドシートID・シート名・DriveフォルダIDを保存

## 画面構成

- **ホーム**：今の状態と次にできる操作（開始／チェックイン／チェックアウト／終了／日報プレビュー）
- **チェックイン**：会社名・担当者名の入力
- **日報**：生成された日報のプレビュー
- **設定**：担当者・連携先IDなどの設定
- **共有受け取り**：他アプリから来た文字起こしテキストの確認・保存

---

## データ（すべて端末内 = Room DB に保存）

- **user_settings**：担当者・連携先設定（1件）
- **work_sessions**：1日の稼働セッション
- **visit_logs**：訪問1件ごとの記録
- **recorder_texts**：録音の文字起こし＋整形＋**AI要約**
- **sync_logs**：Sheets/Driveへの同期履歴

> 列構成（スプレッドシート）：
> 日付 / 担当者 / 営業開始 / 営業終了 / 訪問先 / チェックイン / チェックアウト /
> 滞在(分) / 緯度 / 経度 / 録音メモ有無 / **AI要約** / Drive日報URL / 作成日時

---

## 技術スタック

- **言語/UI**：Kotlin + Jetpack Compose（Material3）
- **DB**：Room
- **位置情報**：Google Play Services Location
- **オンデバイスAI**：要約（差し込み式。Gemini Nano対応端末ではGemini、非対応端末は内蔵ヒューリスティック）
- **構成**：UI → ViewModel → UseCase → Repository → DB/外部API のクリーン分離。軽量DI（ServiceLocator）
